 AUREON CAD / WORKBENCH GUIDE

Precision, by design.

A working, local-first parametric mesh CAD workbench, built with plain JavaScript and a native WebGPU renderer.

Navigate

Drag Orbit the model
Right-drag Pan
Scroll Zoom
F Fit all · 0 Isometric
1 Front · 2 Top · 3 Right
P Perspective · G Grid

Edit

Click a body or a feature in the tree to inspect it. Double-click a feature to edit its definition. Ctrl/Cmd-click adds to selection. Edit dimensions, placement, materials, or suppression in the inspector.

Build

Sketch closed rectangles, circles, or polygons, then pad them. Add real pocket and hole cuts, revolved shafts, feature patterns, and body booleans. Use numeric transforms and exploded views to inspect assemblies.

Save & exchange

Ctrl/Cmd S Download the editable project.
Ctrl/Cmd Z Undo.
Ctrl/Cmd K Search commands.
Import Aureon JSON or STL. Export STL, OBJ, SVG projections, PNG, and CSV bill of materials.

Engineering scope

The kernel is polygonal CSG with tessellated curves—not exact B-rep/NURBS. Mesh-derived mass properties are approximate. No CATPart/CATProduct/STEP compatibility, general edge filleting, assembly constraint solver, CAM, FEA, or CATIA feature parity is claimed. Section views clip surfaces without generating caps. Not validated for safety-critical engineering.
